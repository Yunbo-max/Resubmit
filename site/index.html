Take the right path.

Start with the manuscript you already have. Load only the modules the change actually needs.

03 / Built for revision

The details are the work.

Specialist guidance plus small inspection tools. Not another black-box paper generator.

01

Tables that stay truthful

Track cell provenance, missing values, comparable settings and rankings when rebuttal results change.

02

Figures at the right width

Redraw measured plots from data. Reflow editable diagrams for the target column, not just a smaller canvas.

03

Style with an owner

Separate template defaults from macro overrides, leaked settings and page-building effects.

04

Writing grounded in evidence

Keep claims compatible across the abstract, results, captions and conclusion. Local fixes stay local.

05

Page limits without tricks

Restructure first. Preserve readable text and essential evidence. Never alter official styles to squeeze pages.

06

A verifiable handoff

Compare source snapshots and rendered pages. Package allowed files—not the whole private workspace.

04 / Get started

Bring your paper.
Keep your tools.

Install either or both skills into your local agent. Your host supplies the LLM and browsing; LaTeX editing additionally uses its filesystem and compiler. Normal host usage costs apply.

Setup, updates and troubleshooting ↗
TERMINAL
git clone https://github.com/Yunbo-max/Resubmit.git
cd Resubmit
python scripts/install_skill.py --agent codex --skill selecting-conference-venues
python scripts/install_skill.py --agent codex --skill resubmitting-papers

Installs both skill folders under ~/.agents/skills/. Remove either command to install just one. Existing installations are never overwritten.

05 / Know the boundaries

Checks you can inspect.
Claims we will not make.

The project includes deterministic tests and synthetic one- and two-column LaTeX fixtures. Read the validation records and CI results rather than treating a green check as proof of scientific correctness.

Model recommendations are not independently validated acceptance forecasts. No acceptance guarantees. No fabricated experiments. No universal conference compatibility claim. This website does not accept manuscripts; your agent provider's privacy and compute policies still apply.
