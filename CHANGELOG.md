# Changelog

## 0.3.1 — 2026-10-16

Added a six-stage animated, reduced-motion-aware README workflow; documented domain-aware venue routing and optional K-Dense-style specialist context; introduced a source-linked, qualified open-source capability matrix; updated the renamed repository's public installation URLs. No new model, acceptance predictor, or independent cross-tool benchmark.

## 0.3.0 — 2026-10-13

Added the independently installable `selecting-conference-venues` skill: host-LLM predictions, verified CORE/ICORE and CCF filters, submission-stage eligibility, subjective fit/readiness/outlook and a ReSubmit handoff. No model training or separate prediction service. The installer now supports `--skill` while preserving its original default and non-overwrite behavior. Updated the English README, website, setup and launch copy. LaTeX engine/helper code is unchanged.

## 0.2.0 — 2026-10-13

English public-facing documentation and the ReSubmit display title; a responsive static project site; a reproducible LaTeX before/after demo; a non-overwriting installer; contribution, security, roadmap and citation files; issue templates; CI and opt-in GitHub Pages deployment. The installed skill name and existing LaTeX helper behavior are preserved. Website source readiness does not imply that Pages has been enabled.

## 0.1.2 — 2026-10-12

LaTeX-native editing became the default path. Added source-scope snapshots, rendered PDF comparison and the local-edit DAG. Historical validation recorded 96 tests plus synthetic before/after article fixtures.

## 0.1.1 — 2026-10-12

Added style-baseline and style-audit stages, a LaTeX source scanner and runtime style probes. Historical validation recorded 69 tests.

## 0.1.0 — 2026-10-12

Initial evidence-led resubmission skill with table, figure, writing, layout, QA and packaging contracts. Historical validation recorded 37 tests.
