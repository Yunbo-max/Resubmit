# Roadmap

## Available in v0.3.0

- Host-LLM venue prediction and primary/backup recommendations.
- Official-source CORE/ICORE, CCF, deadline and eligibility checking instructions.
- LaTeX-native editing, scope snapshots, style checks and rendered PDF comparisons.
- Two independently installable skills, English documentation and a static project site.

## Next evidence, not promises

- Evaluate host-agent behavior on authorized, anonymized real venue-selection cases.
- Measure incorrect eligibility recommendations, fit agreement and human revision effort.
- Add real official-template retargeting coverage with permissible redistributed assets.
- Extend regression tests for newly reported failure modes and fresh host environments.

There is no planned mandatory model training or proprietary inference backend.
Accuracy, calibration and acceptance-uplift claims require independent evaluation.
