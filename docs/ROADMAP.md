# Roadmap and evidence boundaries

The public interface is now English, with a static project page and a reproducible synthetic demo. This is an early open-source tool, not a mature guarantee of cross-conference compatibility.

Next priorities: authorized exact-year ICML/ICLR/NeurIPS author-kit fixtures; stronger numerical cross-artifact checks; more realistic wide-table and multi-panel reflow cases; repeatable host-agent evaluations against a strong simple prompt; and clear cross-platform installation tests.

Acceptance criteria matter more than feature count. Report scientific preservation, readable asset text, actual counted pages, final-PDF defects, scope containment and revision effort. Distinguish helper unit tests from agent behavior, and both from real-paper outcomes.

Not planned by default: hosted manuscript uploads, hidden external model calls, autonomous submission, fabricated statistics, template modification to fit, or a large always-on research controller.
